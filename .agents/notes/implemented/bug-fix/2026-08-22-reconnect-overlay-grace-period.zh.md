# Agent Note: 重连覆盖层宽限期

Status: implemented

[English](2026-08-22-reconnect-overlay-grace-period.md) | 中文

## 问题

全屏连接中断覆盖层会在连接进入重连状态后立即出现。因此，即使连接立刻恢复，短暂断线也可能只在一瞬间替换应用并产生可见闪烁。

## 决定

`ConnectionLostOverlay` 会等待重连状态连续保持一秒后再显示。重连仍然立即开始；延迟的只有全屏展示。计时器到期前恢复连接会取消待显示的覆盖层，覆盖层出现后恢复连接则会立即隐藏它。

该延迟归属于展示原始组件，而非连接服务，因此状态订阅方与重新同步保持原有时序。

## 考虑过的替代方案

**延迟重连状态。** 这也会延迟非视觉消费方，并可能推迟重新同步工作，因此连接服务继续立即发布状态。

**为立即出现的覆盖层添加动画或缩短时长。** 任何立即出现的全屏替换仍可能在短暂断线时闪烁，因此动画无法消除这一中断。

## 后果

不足一秒的断线不再覆盖应用。持续中断会比以前晚一秒传达状态，而连接恢复仍会立即反映。

使用假计时器的组件测试和组装布局测试固定宽限期、取消、持续中断显示以及立即恢复行为。模型可见输入没有变化，因此 transcript 快照无需更改。
