# Agent Note：固定会话侧边栏类别

状态：已实现

[English](2026-08-22-pinned-session-sidebar-categories.md) | 中文

## 问题

侧边栏行菜单和会话页头菜单都已有 Session 操作，但两个入口都无法让重要 Session 保持在 Workspace 分组上方。Ungrouped Session 还以虚构的 Workspace 文件夹呈现，使侧边栏层级暗示了并不存在的归属关系。

## 决策

Workspace 注册表在归档集合旁持有一个有序、持久、注册表级全局的固定 Session id 集合。用户可从任一 Session 菜单固定会话。侧边栏行菜单既可通过省略号按钮打开，也可在非空白 Session 行的任意位置右键打开；右键菜单锚定在指针处，并阻止行导航。侧边栏从原投影中移除固定 Session，并只在工作区和未分组两个同级类别上方的已固定类别中渲染一次。固定不会改变 Workspace 记账。归档会以原子方式从固定集合移除该 Session，持久状态会拒绝重复 id 以及归档集合与固定集合重叠。

API 与客户端运行时通过 Workspace 列表基线、固定变更响应和 Host changed 帧交换完整固定快照。这与归档投影的重连及多客户端行为一致。

类别过渡沿用侧边栏现有的短暂淡入上移动效，并遵守减少动态效果偏好。现有的搜索展开动效保持不变。

## 考虑过的替代方案

只把固定状态存入浏览器 local storage 无法跨客户端保留，也无法提供一份权威顺序。把固定 Session 移入特殊 Workspace 会改变其真实记账，并破坏要求的类别关系。在两个位置都渲染固定 Session 则会产生重复导航行。

## 结果

固定 Session 保留其 Workspace，并在取消固定后回到同一个普通类别。未分组不再暴露 Workspace 专用的添加或选项控件。旧注册表状态把新固定集合默认为空，不改变已存储的领域版本。

## 测试

注册表测试覆盖持久性、顺序、幂等性、未知与已归档 Session，以及归档时移除固定。API 测试覆盖一元响应、错误、重连快照和 Host 帧。运行时测试覆盖基线与帧的优先级。组件测试覆盖两个固定入口、按指针定位且不触发行导航的右键菜单、类别顺序、去重，以及从固定行取消固定。
