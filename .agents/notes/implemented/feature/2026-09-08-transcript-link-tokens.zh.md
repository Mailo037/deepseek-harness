# Agent Note：会话链接标签

Status: implemented

[English](2026-09-08-transcript-link-tokens.md) | 中文

## 问题

长 URL 会打断会话阅读，而浏览器通常无法直接获取远程网站的标题。

## 决策

用户的纯文本消息和助手的 Markdown 消息共用紧凑的 HTTP(S) 链接渲染器。网站链接显示图标和标题；无法获取元数据时保留原标签或主机名。文件链接显示文件名和类型图标，配置文件使用齿轮，PDF 使用 PDF 标记。目标地址和日志中的原文保持不变。

现有 Host API 提供仅含标题的预览请求，浏览器无需跨域读取 HTML 或使用第三方预览服务。每次重定向都验证公网地址并固定 DNS 结果。响应字节数、重定向次数和耗时都有上限。会话所有者缓存请求 Promise；URL 改变后渲染器忽略旧结果。

## 考虑过的替代方案

浏览器直接请求通常无法读取跨域页面标题。第三方元数据服务会向其他运营者披露会话 URL。HTML 预览会增加不必要的活动内容和资源请求。

## 影响

标题依赖可访问的公网网站。预览失败时保留原标签或主机名；日志仍保留原始消息。

## 验证

组件测试覆盖两种消息方向、目标地址保留、标题回退、过期结果、文件分类和图标失败。宿主测试覆盖公网 DNS 固定、私网目标、重定向、响应限制和错误处理。无需密钥的浏览器场景记录两种消息方向，并检查桌面与移动端标签宽度。
