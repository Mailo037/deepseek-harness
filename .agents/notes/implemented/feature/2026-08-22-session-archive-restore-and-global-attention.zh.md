# Agent Note: 会话归档恢复与全局注意状态

Status: implemented

[English](2026-08-22-session-archive-restore-and-global-attention.md) | 中文

## Problem

已归档会话需要返回保留的工作区归属，而需要操作员处理的会话状态分散在普通侧边栏层级中。

## Decision

`WorkspaceRegistry.unarchiveSession()` 会从持久化归档集合移除 id，而不改变其工作区归属。主机公开反向 `workspace.unarchiveSession` RPC 及完整归档集合响应；运行时会在对应注册表帧到达前安装该响应。

侧边栏提供已归档与需要关注视图。需要关注会直接过滤权威会话摘要，涵盖待审批、问题、计划审查、重试耗尽失败、已完成后台工作、运行会话和运行子代理。折叠的工作区行只要隐藏成员符合相同投影条件便显示警告标记。归档成功提供撤销，归档或恢复失败保持可见并提供重试动作。

## Alternatives considered

### 删除归档会话记录

被否决，因为归档是可见性选择而非删除；保留现有归属可让恢复的会话回到原分组和顺序。

### 从已渲染侧边栏行推导注意状态

被否决，因为折叠分组和未选中会话可能没有渲染行。视图直接从会话与投影注册表派生。

## Consequences

- 归档和恢复都是幂等的持久化注册表操作。
- 注意视图包含已完成和运行中的后台活动，也包含阻塞与失败状态。
- 当前列表中尚无摘要的会话会在其摘要基线到达前暂不显示于已归档视图。
